# 第一次比较实验：十分钟示例

先运行安装包中的演示命令：

```bash
python scripts/statelens.py demo --out demo-report --open
```

这会创建一个本地报告，不需要连接助手或上传文件。示例全部为人为构造的数据，用于学习操作，不代表真实实验发现。

## 先回答三个问题

1. **比较什么？** 例如“同一测试集上，缓存是否降低模型响应时间”。
2. **什么算一次实验？** 例如独立准备的一批试样、一次独立运行；不是一条曲线中的每个采样点。
3. **哪些条件应保持相同？** 例如仪器、批次、测试协议、负荷、样本划分。

这些信息比选择图表更重要。没有足够的信息时，仍可比较观测值，但不宜判断是哪一个因素导致了变化。

## 阅读演示报告

选择计算机科学示例，候选状态选择“增加缓存”。先看条件变化，再看响应时间和准确率。来源中一部分响应时间以秒保存，报告统一成毫秒；单位换算必须发生在求差之前。

“差值”是候选状态减去对照状态。“改善幅度”会依据指标目标调整方向：对于响应时间，降低才是改善。因此负差值可以对应正改善幅度。

“实际意义阈值”表示你认为值得关注的最小改善，例如 3 毫秒。改变阈值只会改变判断标准，不会改变观测数据或重新测量。先设定标准，再分析数据更适合正式研究；事后调整应作为敏感性分析说明。

选择材料科学中的“换了测试协议”，查看为什么报告限制更强结论。数值可能更高，但测试条件也改变了，无法仅把差异归因于材料处理。

## 换成自己的文件

将表格、实验记录和相关图片放在一个专用文件夹中，避免混入无关资料。给助手如下任务：

```text
使用 compare-experiments 分析这个文件夹。
先根据记录识别对照组、实验组、指标和独立重复单位，
保留每个数据的文件/工作表/行号来源。
能确定的直接处理；缺失条件先标注，不要猜测。
生成比较报告，并解释哪个结论最需要补做实验。
```

助手会生成提取清单与 `dataset.json`，然后生成 `report.html`、`report.json`、`comparison.csv`、`summary.md`。其中 `dataset.json` 是以后复算的输入；报告 JSON 保存计算结果；网页用于检查和探索；CSV 可供其他统计工具继续处理。

## 如何理解暂时无法下结论

“证据仍不确定”表示现有区间尚不能明确支持改善、变差或差异处于阈值范围内。“有效数据不足”提示检查独立重复次数、缺失值或配对关系；“可比性受限”提示先核对实验条件。这些状态都不等同于“没有差异”。同样，均值更好也不代表该方案在所有样本或未来实验中都会更好。

## 学科迁移时要保留什么

| 场景 | 常见独立实验单位 | 常见比较条件 |
|---|---|---|
| 材料 | 独立制备试样或独立批次 | 制备批次、测试协议、温湿度 |
| 化学 | 独立反应批次 | 原料、浓度、仪器校准、反应时长 |
| 生物 | 独立生物样本或实验个体 | 批次、培养条件、采样时间；技术重复应单独处理 |
| 计算机 | 符合设计的独立种子/任务批次 | 数据划分、硬件、预处理和评估协议 |
| 热流工程 | 独立工况运行或独立试验批次 | 负荷、环境边界、传感器校准、稳态窗口 |

这些是提示，不是各学科的通用统计方案。层级数据、重复测量、时间相关数据或复杂实验设计通常需要专门模型；先用描述性模式整理证据，再选择合适方法。
