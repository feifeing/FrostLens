# FrostLens 计算方法与解释边界

本文对应 `frostlens/model.py`、`frostlens/core.py` 的 0.1.0 实现。FrostLens 用于稳态复叠制冷的模型检查、局部参数信息诊断和下一组实验选择。自带数据全部为合成数据；目前没有真实设备上的精度验证或故障识别验证。

## 1. 热力学模型

低温级使用 CO₂，高温级使用 NH₃；两级均采用 CoolProp 的 HEOS 物性后端。状态计算通过 `AbstractState` 的饱和温度和压力—熵输入完成，接口依据 [CoolProp 低层接口文档](https://coolprop.org/coolprop/LowLevelAPI.html)。压缩机吸气为饱和蒸气、冷凝器出口为饱和液体，因此过热度和过冷度均为 0。节流等焓，忽略压降和外界热漏。

对于单级循环，记蒸发出口焓、熵为 `h1, s1`，冷凝出口焓为 `h3`，冷凝压力下等熵压缩出口焓为 `h2s`。单位制冷量的理想压缩功比为：

```text
R(Te, Tc) = (h2s - h1) / (h1 - h3)
```

给定四个工况输入 `te_c, tc_c, tm_c, load_kw`，计算：

```text
W_low  = Q_load × R_CO2(te, tm) / eta_low
Q_cas  = Q_load + W_low
Te_NH3 = tm - Q_cas / UA
W_high = Q_cas × R_NH3(Te_NH3, tc) / eta_high
P_total = W_low + W_high + P_aux
```

温度以 °C 输入，温差为 K，功率为 kW，UA 为 kW/K。`tm_c` 专指 CO₂ 凝结温度，NH₃ 蒸发温度由复叠换热量与等效 UA 决定。该 UA 是此简化稳态模型的有效参数，尚未描述几何结构、分布温度、污垢或动态储热。

`eta_low, eta_high` 为等熵效率，电机效率固定为 1；因此压缩机项是热力学压缩功，模型没有单独换算电机损耗。真实电表数据的应用需要先校准此假设，或扩展电机模型。`P_aux` 是单独的固定辅助功率。

| 参数 | 下限 | 上限 |
| --- | ---: | ---: |
| 低温级等熵效率 `eta_low` | 0.40 | 0.90 |
| 高温级等熵效率 `eta_high` | 0.40 | 0.90 |
| 等效 UA `ua_kw_k` | 0.60 | 6.00 |
| 固定辅助功率 `aux_kw` | 0.00 | 2.00 |

参数在全部测量期间恒定。输入温度和负荷视为准确，当前没有传播这些输入的不确定度。

## 2. 数据与可计算域

| 输入 | 模型接收范围 | 默认实验搜索范围 |
| --- | --- | --- |
| `te_c` | [−52, −20] °C | [−48, −28] °C |
| `tc_c` | [15, 50] °C | [24, 44] °C |
| `tm_c` | [−18, 5] °C | [−15, 2] °C |
| `load_kw` | [0.5, 16] kW | [4, 14] kW |

还要求 `tm − te ≥ 8 K`、`tc − tm ≥ 12 K`、推导出的 NH₃ 蒸发温度高于 −70 °C 且低于其凝结温度。物性状态必须有效，计算出的制冷量和压缩功必须为正。

分析接受 4–250 行测量。四行只是当前 API 的最小数据量要求；重复工况即使有很多行，也不能保证四个参数可区分。功率必须在 `(0, 10000] kW`，标准差必须在 `(10⁻⁶, 10000] kW`，不能使用 NaN、无穷数或布尔值。提供低温级功率时，它必须小于总功率。这些范围是软件输入检查，不能替代具体设备的运行限制。

`power` 模式使用总功率；`split` 模式还使用低温级功率，并要求相应的 `sigma_low_kw`。标准差表示单次观测的测量不确定度，单位与功率一致。

## 3. 加权拟合与求解状态

将每个参数按其完整上下界归一化：`x = (p − LOWER) / SCALE`，其中 `SCALE = UPPER − LOWER`，故 `x ∈ [0,1]⁴`。总功率残差为：

```text
r_total,i = (P_model,i - P_observed,i) / sigma_i
```

分项模式逐行追加同形式的低温级功率残差。最小化 `SSE = Σ r²`；SciPy 接口内部的成本为 `SSE / 2`。本项目使用默认的线性损失与有边界 TRF 求解器，详见 [SciPy least_squares 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。没有稳健损失、先验正则项或噪声重新估计。

三个固定的四维初值为：

```text
[0.60, 0.60, 0.25, 0.20]
[0.20, 0.80, 0.75, 0.05]
[0.85, 0.25, 0.10, 0.60]
```

每次四维求解最多 120 次残差函数求值；`ftol = xtol = 10⁻⁹`，`gtol = 10⁻⁸`。随后进行第 5 节的有限剖面搜索。若某个剖面点比当前最佳四维候选更好，则从该点释放全部四个参数再求解，允许最多 120 次函数求值；已不可能改善当前最佳值的剩余剖面点不再精修。最终最佳拟合只能来自四维求解，固定一个参数的三维剖面收敛不能代替四维收敛。

报告的 `fit.weighted_sse` 是完整加权 SSE；`fit.residual_count` 在总功率模式为 n，分项模式为 2n。`fit.search_method` 为 `multistart` 或 `profile_polish`；`fit.converged` 对应该四维候选的 SciPy 收敛标志。多初值与有限预算不能保证全局最优，收敛标志也不能证明物理模型正确。

总功率 `rmse_kw` 为未加权的总功率残差 RMS。`weighted_rmse = sqrt(SSE / residual_count)` 同时计入所选通道；它没有按自由度进行修正。展示字段 `residual_kw` 使用“观测减预测”，其符号与求解器残差相反，但不影响平方误差。

若加权 RMS > 2.5，状态为 `mismatch`；否则按下一节的有效方向数区分 `informative` 和 `weak`。2.5 是提示模型检查的约定阈值，未按样本数校准，不是显著性检验，也不能据此定位故障。参数归一化值小于 0.001 或大于 0.999 时会提示贴近边界。

## 4. Jacobian 与两种“秩”

Jacobian 对归一化参数求导，并将每一观测除以其标准差：

```text
J_ij = (∂P_i / ∂p_j) × SCALE_j / sigma_i
J = U diag(s) Vᵀ,   s1 ≥ s2 ≥ s3 ≥ s4 ≥ 0
```

大部分物理导数为解析表达式；NH₃ 理想功比对蒸发温度的导数使用步长 0.001 K 的中心差分。没有通过舍入温度缓存近似物性。奇异值分解使用 [NumPy SVD](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)。

- **有效方向数**（历史字段名 `summary.rank`）：奇异值 `s ≥ 1` 的个数。它表示在当前参数范围与噪声尺度下，一个单位归一化参数组合变化，在局部线性近似中产生至少单位噪声尺度的总响应。阈值 1 是描述性尺度，改变参数边界或标准差会改变结果；有限边界和非线性也可能限制此局部解释。
- **数值秩** `summary.numerical_rank`：奇异值大于 `s1 × max(J.shape) × machine_epsilon` 的个数。它只检查浮点精度下的线性独立性；数值满秩仍可能有很弱的实际信息。
- **条件数**：在 `s4 > max(s1 × 10⁻¹², 10⁻¹²)` 时为 `s1 / s4`，否则返回 `null`，表示接近数值奇异，而非条件数为零。
- **最弱方向**：`V` 对应最小奇异值的向量，给出参数归一化坐标中的组合变化。整体符号可以翻转；若多个方向同样弱，单个向量也不唯一。

这些都是当前最佳拟合点的局部指标。有效方向数为 4 不证明全局唯一，也不提供置信区间。当前没有把边界约束投影到切空间后再计算指标。

## 5. 替代解释搜索

从初始最佳四维解的最弱方向中，选择绝对权重最大的一个坐标。依次将该归一化坐标固定为 `0.03, 0.32, 0.65, 0.97`，优化其余三个坐标，各最多 100 次残差函数求值，使用相同容差。它是有限的、有边界的剖面搜索，不是完整 profile likelihood 区间计算。

多初值结果、剖面点和追加的四维精修结果共同构成候选集。替代解释要求：

```text
SSE_alternative ≤ SSE_best + 3.84
distance = ||x_alternative - x_best||₂ / 2 ≥ 0.12
```

满足条件时展示距离最大的候选。3.84 与 0.12 均为展示筛选规则；本实现没有证明其覆盖率，不能将结果称为 95% 置信区间。剖面候选的三个自由坐标可能达到预算而未收敛，但展示的 SSE 仍由该实际参数点的预测计算。没有找到候选也不证明解唯一。

## 6. 顺序局部 D-optimal 实验选择

每个工况输入在用户范围内取下限、中点、上限；零宽度范围去重，因此最多 `3⁴ = 81` 个候选。移除不满足温差约束或物性计算失败的点。预算为 1–5；实际可返回的点数不超过有效候选数。

未来观测标准差取当前各通道标准差的中位数，并假设所有未来工况使用该标准差。全部候选在当前最佳参数处计算 Jacobian。设累计观测矩阵为 `J`，一个候选的观测行组为 `B`，其信息增量分数是：

```text
A = JᵀJ + λI,       λ = 10⁻⁶
gain = log det(A + BᵀB) - log det(A)
```

`λ` 是归一化坐标中的固定绝对 ridge，不随矩阵迹或传感器噪声缩放，也不加入拟合目标。它使设计准则在信息不足时仍有定义，会影响弱信息情形的排名。

实现使用 SVD 与行列式恒等式稳定计算增量：若 `J = U diag(s) Vᵀ`，构造 `C = B V diag(1 / sqrt(s² + λ))`；取 C 的奇异值 `t` 后，`gain = Σ log(1 + t²)`。这样无需显式构造、求逆或相减大尺度的 `JᵀJ`，避免在很小噪声下丢失绝对 ridge。

每轮选出 gain 最大的候选，移出本次候选集，再把 B 追加到累计 J；因此同一批建议内没有重复点。与历史测量相同的工况仍允许被选中，代表独立重复测量。每步报告累计矩阵最小奇异值的前后变化。选择期间不生成数据、不重新拟合；实际测量加入后重新分析才完成闭环。

这是当前估计点上的、有限网格的贪心局部设计，没有对参数不确定度积分，也不是连续设计域的全局最优。存在模型失配时仍会计算条件于该模型的建议，并给出提示。

替代模型差异 `separation_sigma` 在单通道下为 `|ΔP|/sigma`，双通道下为两个标准化预测差的欧氏范数。它是辅助展示量，**不是选点目标、可区分概率或预期信息增益的概率解释**。

## 7. 噪声独立性

各行及各通道均按已知标准差的独立高斯测量噪声处理。特别是分项模式：总功率和低温级功率必须被当作具有独立误差的观测。若总功率由分项求和，或共用传感器、校准误差、采样链路，通常需要非对角协方差矩阵；当前实现不支持这种相关噪声。

忽略相关性会错误计算加权 SSE 和信息量，不能仅凭增加一个派生通道宣称实验信息增加。合成数据刻意独立采样两个通道的噪声，使演示与计算假设一致。

## 8. 合成案例与复现

`narrow` 为相近工况的 12 次测量，`wide` 为覆盖不同温度和负荷的 16 次测量。二者生成参数均为 `[0.70, 0.74, 1.80, 0.35]`。总功率噪声标准差为 0.045 kW，低温级为 0.025 kW。

`drift` 使用与 wide 相同的 16 个工况，其低温级真实效率随全局、从 0 起的测量序号 i 改变：

```text
eta_low(i) = 0.74 - 0.22 × min(i / 15, 1)
```

因此从第 1 行的 0.74 降至第 16 行的 0.52，后续追加行保持 0.52。分析仍拟合恒定参数，这是刻意设置的模型外案例。序号不应在追加测量时重置；连续追加使用已有行数作为下一次序号。

每次虚拟测量将案例 id、工况和序号序列化，经 SHA-256 的前 8 字节生成 NumPy 随机数种子。同样输入可以重复生成同一测量；将重试当作新测量会改变实验含义。此机制用于可重复演示，不提供真实实验数据或真实设备验证。

报告记录模型版本以及 NumPy、SciPy、CoolProp 版本。跨依赖版本、数值平台的结果可能有细微差异；严谨复现实验应保存数据、参数边界、设计范围、传感器模式和依赖版本。

## 9. 验证范围

核心测试覆盖独立焓平衡计算、完整有限差分导数校验、参数与运行域角点、无噪声参数恢复、替代候选的实际预测误差、独立分项信息增量、极小噪声和重复工况、实验范围约束以及合成闭环。求解器回归测试还强制出现“剖面比未收敛多初值更好”的情形，确认最佳结果释放四个参数后才被采用，并保留真实收敛标志。

这些检查验证实现一致性和指定案例的行为，不能替代真实设备数据验证、结构可辨识性证明、全局优化证明或正式不确定度分析。
