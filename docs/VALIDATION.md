- **21 项浏览器检查通过**：虚拟实验闭环、测量方式切换、数据保留、固定工况范围、CSV 导入和错误反馈、报告导出、对话框键盘操作、离线案例切换、手机布局、无脚本错误和无外部网页请求。
- 构建了标准 `.whl` 安装包，并在本工作区的独立虚拟环境成功安装其依赖。运行和测试不依赖作者的研究目录。

## 科学检查是什么

1. 用独立的 CoolProp `PropsSI` 焓值计算核对主实现的低层 `AbstractState` 循环结果。它验证程序与能量方程的一致性，不是独立物性数据库验证。
2. 用完整有限差分核对解析/半解析 Jacobian。
3. 检查允许工况域与参数域的有效端点、UA 增加降低功率、无噪声宽工况参数恢复。
4. 核对替代解确实满足残差阈值，而非为展示手工设定。
5. 独立核对 D-optimal 增益，检查重复工况和极小噪声时的数值稳定性。
6. 检查分项独立观测增加半正定信息、顺序推荐不重复选同一候选、所有输出可用严格 JSON 序列化。
7. 回归检查更优剖面候选必须重新释放全部参数优化，不能把三维收敛当作四维收敛。
8. 检查漂移案例追加测量沿全局序号继续，而不是重新开始漂移。

## 一个可复现的演示结果

默认窄工况案例只拟合总功率；每次选择最新排名第 1 的推荐点，追加一条合成测量并重新拟合：

| 测量数 | 可约束的局部方向（奇异值 ≥ 1） | 缩放 Jacobian 条件数 |
|---:|---:|---:|
| 12 | 2 / 4 | 4582.67 |
| 13 | 3 / 4 | 2776.05 |
| 14 | 3 / 4 | 1470.95 |
| 15 | 4 / 4 | 36.17 |

初始 RMSE 约 0.0396 kW，三次追加后约 0.0382 kW。关键变化是参数信息，而不是把训练误差压到更小。这里的“4 个方向”仍是局部、尺度相关的描述，不能解释为全局唯一性证明。

单独生成三个默认报告时，本机分析耗时分别约 1.15 秒、0.34 秒、0.46 秒。耗时受缓存、硬件、数据量和收敛情况影响，不作为性能保证。

## 如何复算

```bash
python -m unittest discover -s tests -v
python tools/rebuild_examples.py
python tools/reproduce_sequence.py
```

可选浏览器验证：安装 Node.js 和 Playwright，启动本地服务后运行：

```bash
npm install --no-save playwright@1.62.1
npx playwright install chromium
node tests/browser.mjs
```
